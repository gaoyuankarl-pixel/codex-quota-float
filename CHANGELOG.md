# Changelog

## 0.2.0 — 2026-11-04

First public bilingual release.

- English by default for new installations; Simplified Chinese selectable from the language menu.
- Existing Chinese installations retain language, opacity, and position.
- Translated labels, menus, status, errors, reset confirmation, and retry messages.
- Portable source layout, clean packaging, bilingual documentation, Windows build/release workflow.
- Retains compact overlay, clockwise quota consumption, prefixed countdowns, foreground-only display, independent watcher, and persistent idempotent reset redemption.

首次公开双语版本：新增英文和语言切换，保留原中文设置；提供中英文说明、可复现构建、干净发布包和 Windows 自动构建。保留圆环、倒计时、前台限制、自启动监听及幂等重置。
